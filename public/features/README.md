Feature logos go here, named after the feature's slug: americano.svg, mexicano.svg,
clubs.svg … See docs/FEATURE_LOGOS.md for the full list and the prompt for each.

Either .svg or .png works — FeaturePoster tries .svg first, then .png, then falls
back to the vector poster drawn in FeaturePoster.tsx. A missing file is not an
error, so the set can be filled in one at a time.
